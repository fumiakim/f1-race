# F1 RACE — レトロ・グランプリ

### ▶ [ブラウザでプレイする](https://fumiakim.github.io/f1-race/)

任天堂のファミコン用ソフト「F1 Race」(1984) へのオマージュとして作った、疑似3Dのレトロレーシングゲームです。
依存ライブラリなしの **単一HTMLファイル**（Canvas + 素のJavaScript）で、ブラウザで開くだけで遊べます。

## 遊び方

上のリンクからそのまま遊べます。ローカルで動かす場合は `index.html` をブラウザで開くだけです。ビルド不要。

ローカルサーバー経由で開く場合:

```bash
python3 -m http.server 8177
# → http://localhost:8177
```

## モード

タイトル画面で `↑` `↓` を押して選び、`Enter` で決定します。

- **1 PLAYER** — タイムアタック。制限タイム内に3周を目指します。ベストラップはコースごとに保存されます。
- **2 PLAYERS** — 左右分割画面での2人同時対戦。先に3周した方が勝ちです。

## 操作（ファミコン風）

### 1人プレイ

| キー | 動作 |
| --- | --- |
| `X` | アクセル |
| `Z` | ブレーキ |
| `←` `→` | ハンドル |
| `Shift` | ギア切替（LOW / HIGH） |

### 2人同時対戦

| | 1P（左画面） | 2P（右画面） |
| --- | --- | --- |
| アクセル | `W` | `↑` |
| ブレーキ | `S` | `↓` |
| ハンドル | `A` `D` | `←` `→` |
| ギア切替 | `Q` | `Shift` |

### 共通

| キー | 動作 |
| --- | --- |
| `↑` `↓` | メニュー選択 |
| `Enter` | 決定 / スタート |
| `Esc` | 前の画面へ戻る |
| `M` | サウンド ON/OFF |

## コース

タイトルで `Enter` を押すと、6種類のコースから選べます。コースごとに周回距離・ライバル数・制限タイムが異なります。

| コース | 背景 | 特徴 |
| --- | --- | --- |
| BEGINNER | 昼・緑地帯 | 比較的ゆるいコーナー。まずはここから |
| SEASIDE | 夕焼け | S字カーブの連続 |
| MOUNTAIN | 砂漠 | 起伏の激しいコース |
| TECHNICAL | 雨 | 急カーブが連続するテクニカルコース |
| CITY | 夜・市街地 | 直角気味のコーナーが多い |
| GRAND PRIX | 夕暮れ | 全要素を含む最長・最難関 |

コースごとに背景（空・地面・遠景・天候）が変わります。

コーナーは全開のままでは曲がり切れません。遠心力でコース外へ押し出されるため、進入前にブレーキで速度を落とす必要があります。

## ギアのコツ

実車と同じく、**発進は LOW ギアから**。HIGH ギアは低速だとトルクが細く、停止状態から入れてもほとんど加速できません。LOW で十分に速度を上げてから HIGH に切り替えると伸びます。

## 特徴

- **疑似3Dの道路** — 地平線に収束する路面、丘の起伏、左右カーブ、赤白の縁石、破線のレーンマーカー
- **ファミコン風の見た目** — 限定パレット、内部解像度 320×240 をピクセル拡大、CRTスキャンライン、アーケード筐体フレーム
- **2段ギア** — LOW（約138km/h・加速重視）と HIGH（約300km/h・伸び重視）を使い分ける
- **走行の手応え** — 遠心力でカーブの外へ流される、コース外（芝生）に出ると大幅減速
- **ライバル車** — 追い越しをカウント。接触すると火花が散り、速度が著しく低下
- **丘のオクルージョン** — 手前の丘で道路が見えない位置のライバルは正しく隠れる
- **ミニマップ** — 左上にコースの見取図と自機（赤）・ライバル（黄）の位置をリアルタイム表示
- **6コース** — それぞれ異なるレイアウト。選択画面で見取図をプレビュー
- **コースごとに異なる背景** — 昼の緑地帯・夕焼け・砂漠・雨・夜の市街地・夕暮れ。空／地面／遠景／天候が変化する
- **ベストラップの保存** — コースごとの自己ベストを `localStorage` に保存し、次回起動時も保持
- **2人同時対戦** — 左右分割画面。各プレイヤーが1人プレイと同じ 320×240 のフル視界を持ち、相手のマシンは自分の画面にも見える（接触すると両者とも火花を散らして減速）。**音も画面の位置に合わせて 1P＝左スピーカー / 2P＝右スピーカー** から出るので、自分のエンジン音を聴き分けられる
- **3周＋制限タイム** — ラップ完了ごとにタイム加算。タイムアップでゲームオーバー（対戦モードは制限タイム無しの先着勝負）
- **サウンド** — Web Audio によるエンジン音・タイヤのスリップ音・クラッシュ音・効果音（外部ファイルなし）。ブレーキ中やコース外走行中はタイヤが鳴き、2人対戦ではプレイヤーごとに独立した音を左右へステレオ定位

## 技術

- 素の JavaScript（IIFE）、外部依存ゼロ、ビルド工程なし
- 疑似3D道路は [Jake Gordon 氏の解説](https://codeincomplete.com/articles/javascript-racer/) と同系のセグメント投影方式
- マシンのスプライトは Canvas の矩形描画による procedural 描画（画像アセットなし）
